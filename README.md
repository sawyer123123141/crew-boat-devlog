# Crew Boat — devlog

A co-op boat delivery game made in Godot 4. Your crew carries a crate across open water from one port
to the next. On the way there are storms, fog, waterspouts, leaks, flooded decks and engine fires. Someone
steers, someone bails, someone patches the hull, and someone fishes whoever went overboard back out with the lifebuoy.

![The harbour tug in a storm](media/harbour-tug/tug-storm.gif)

This repo is only the progress diary: posts, screenshots and clips. The game's code lives elsewhere.
